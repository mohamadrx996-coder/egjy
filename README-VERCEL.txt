  HANNIBAL .#1888 — دليل النشر على استضافة Vercel
  (نفس النسخة الكاملة — كل الأدوات + الكويستات + البرايم)
═══════════════════════════════════════════════════════════════

  ✦ ما فيه أي متغيرات بيئة — كل شي مدمج بالكود مثل النسخة القديمة
  ✦ ما تحتاج قاعدة بيانات ولا أي خدمة إضافية — ارفع وانشر وخلاص

■ الطريقة الأولى — عبر GitHub (الأسهل):

  1) ارفع مجلد المشروع على مستودع GitHub جديد
     (ما ترفع مجلدات node_modules و .next — ملف .gitignore يمنعها تلقائياً)

  2) ادخل vercel.com وسجل دخول (يفضل بحساب GitHub)

  3) اضغط Add New... → Project → اختر المستودع → Import

  4) اضغط Deploy مباشرة — بلا أي إعدادات ولا متغيرات
     وبعد دقيقة تقريباً يصير موقعك جاهز على رابط
     مثل:  https://اسم-مشروعك.vercel.app

■ الطريقة الثانية — عبر Vercel CLI من جهازك:

  npm i -g vercel
  داخل مجلد المشروع:  vercel  →  ثم  vercel --prod

═══════════════════════════════════════════════════════════════
  ملاحظات مهمة بعد النشر
═══════════════════════════════════════════════════════════════

• الكويستات على Vercel تشتغل والصفحة مفتوحة (السيرفر ينفذ والصفحة
  تستفسر كل ثانيتين). لو قفلت الصفحة فترة طويلة اضغط "نفّذ من جديد"
  وسيكمل من حيث وصل — تقدمك محفوظ عند ديسكورد نفسه.

• العداد الحي والأدوات كلها تعمل كما هي — ما فيه أي فرق بالاستخدام
  بين النسخة المحلية ونسخة Vercel.

• الحسابات والحالة محفوظة بذاكرة السيرفر (مثل النسخة القديمة تماماً)
  — لو الاستضافة أعادت التشغيل سجل دخول بحساب trojan/1888 وكمّل عادي.

• محلياً:  npm install  ثم  npm run dev  — وبس، بدون أي ملفات إعداد.
